# matasCafeRoyaSintetV1
Imágenes de arbustos de café en una plantación real, procesados con el algoritmo "genRoya" para generarles roya sintética (NO Redes Adversativas/GAN)

Dataset: RS-V1 - Roya Sintética en Café en Mesosistema V1 Imágenes de matas de café procesadas con "genRoya", un algoritmo para generar roya sintética. El dataset está conformado por 274 imágenes en JPG de matas de café.

Origen: Finca Guadalupe, Coatepec, Veracruz, México Propósito: investigación y docencia Proyecto: Sistema de Gestión de Riesgo Basado en Agentes Autónomos (SATBAA) - bdi-dr.cua.uam.mx - DCCD.TI.PI-64 y DCCD-TI-PI.103, y sus proyectos posteriores.
